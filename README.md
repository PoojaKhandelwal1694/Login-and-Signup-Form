# Login & Signup Form

This project is a simple user authentication interface created using HTML and CSS. It includes a Login page and a Signup page connected through navigation links, allowing users to switch between account login and registration forms. The project is designed to help beginners practice form creation and user interface design.

## Features

* Login Form
* Signup Form
* User-friendly interface
* Gradient background design
* Form input fields for user information
* Navigation between Login and Signup pages
* Basic validation elements using HTML input types

## Technologies Used

* HTML
* CSS




## Pages Included

### Login Page

The login page allows users to enter their email/phone number and password. It also includes a "Forgot Password" option and a link to the signup page.

### Signup Page

The signup page collects user information such as:

* First Name
* Last Name
* Gender
* Date of Birth
* Mobile Number
* Email Address
* Password

It also includes a Terms & Conditions checkbox and a link back to the login page.

## How to Run

1. Download or clone the repository.
2. Keep both HTML files in the same folder.
3. Open `index.html` in any web browser.
4. Use the Signup link to navigate to the registration page.
